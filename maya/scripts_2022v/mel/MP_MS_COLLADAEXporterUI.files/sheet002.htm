説明
■インストール
１・スクリプトをローカルで使用する
MP_MS_matterSetup.mel
MP_MS_toroExporterUI.mel
を所定のフォルダにコピー
２・設定を変更
MP_MS_toroExporterUI.mel
下記行を書き換える
・ToroToolのパス
global string $TOROTOOL_PATH="D:/MProject/ToroTool.exe";
・MP_MS_matterSetup.melのパス
global string $MP_MATTER_SETUP = "Z:/z_sakai/MP_MS_tools/MP_MS_matterSetup.mel";
■起動
１・MAYAでスクリプトを実行
MAYAのスクリプトエディタで下記コマンドを入力
source "【フォルダへのパス】/MP_MS_toroExporterUI.mel";MP_MS_toroExporterUI;
例）
source "D:/MP_MS_tools/MP_MS_toroExporterUI.mel";MP_MS_toroExporterUI;

s000192_EoJ_WorkHelper_UI



機能：   EOJ　PSPにて作業効率を上げられそうなツール郡を纏めボタンから起動します。

機能説明：

ボタン郡：                登録されているスクリプトをボタン表示

Closeボタン：            スクリプト終了



使用法：

ボタンを押すのみで対応のスクリプトを実行します。また、ボタン上部にカーソルを合わせる事で簡易の

ツールチップを表示します。

 

 

mel登録方法：

以下は実際にmel作成後にこのスクリプトにそのコマンドを登録する手法を説明。

D:\EOJPSP\tools\mel\s000192_EoJ_WorkHelper_button.txt　に必要な情報を記載します。

フォーマットは単純なTAB区切りで前から　ボタンの名前　コマンド名（実行proc名）　melファイル名　ツールチップテキスト

の４つからなります。

TABで区切らずに文字列を記載すると見出し用のテキストで表示されます。

上記参考イメージの場合以下の3行の記載になります。

 

-----Chara Make Help-----

set piv[]s000192_EoJ_reset_piv[]s000192_EoJ_WorkHelper.mel[]選択形状（複数可）をfreezeしpivotを０原点に設定

view one node[]s000192_EoJ_View_One[]s000192_EoJ_WorkHelper.mel[]重なった形状の中から一個のみ表示（キャラ表示用）

 

[]がTABが入っている場所です。

 

s000192_EoJ_WorkHelper_UI　はスクリプト起動時にこのテキストファイルを読み込み、中に書き込まれた

mel（必ずD:\EOJPSP\tools\mel\以下にそのmelファイルが存在する必要があります）をsourceします。

フォルダ内にmelファイルが無い場合はその旨のエラーメッセージを表示します。

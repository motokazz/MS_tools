The Spiralizer plugin for Maya allows modelers to create a spiral on a surface.

Installation:
-------------
Copy the spiralizer.mel and spiralizerUI.mel in x:\?\?\Autodesk\maya.x\scripts 
Mac: home/Library/Preferences/Autodesk/maya/20xx-x64/prefs/scripts
     home//Library/Preferences/Autodesk/maya/20xx-x64/prefs/icons
                                               

Copy the spiralizer.bmp to your maya icons folder.

Start maya and type  spiralizerUI;  into the command-line or create a shelf button.
(open the script editor and type in:    spiralizerUI;    highlight it 
and drag it to the shelf using the middle mouse button.)
open the shelf-editor and choose the spiralizer.bmp icon from the path you put it.

Usage:
------
To make a spiral, create any nurbs primitives (cylinder without caps, a cone or a sphere), 
deform it or tweak CV's to get the shape you want. then open the Spiralizer, 
select the object, enter the number of turns (0-500) and hit create.
